# FrameFinder — Image Search UI

## Overview

FrameFinder is a responsive image-search interface built using plain HTML, CSS, and JavaScript, without frameworks, libraries, or build tools.

## Features

- Labeled search input and Search button
- Nature, Animals, and Travel category buttons
- Responsive CSS Grid ready for future image results
- Mobile-friendly layout
- Empty results container prepared for Part 2

## Design Decisions

### 1. Blue-and-white colour theme

I chose blue to create a calm, focused visual experience suitable for an image-discovery tool. White backgrounds on controls and the results area provide contrast, helping users distinguish interactive elements from the page background.

### 2. Category buttons above the results area

I placed Nature, Animals, and Travel buttons near the search form so users can quickly identify possible search categories. This layout establishes a clear flow from entering a search to exploring results and leaves room for additional categories in future iterations.

## Project Structure

- `index.html` — semantic page structure and search controls
- `styles.css` — visual styling and responsive grid
- `script.js` — search form interaction
- `README.md` — project documentation

## Running Locally

Open `index.html` in a web browser. The Search button does not fetch images yet because this submission covers Part 1.
