## About FrameFinder

FrameFinder is a responsive image search interface built with
plain HTML, CSS, and JavaScript.

### Features
- Search input and search button
- Nature, Animals, and Travel category buttons
- Responsive CSS Grid for future image results
- Blue-and-white colour theme

### Project Files
- index.html — page structure
- styles.css — styling and responsive layout
- script.js — JavaScript interactions
- README.md — project documentation

### Current Stage
Part 1: UI scaffold. Image search functionality will be added
in Part 2.

### Run Locally
Open index.html in your browser.
